# Legacy Database Engine Discovery — PROD-WP10

> **Target System:** XT-POS  

---

## 1. Engine Profile

- **Database Engine:** Visual FoxPro / dBase IV File Format (`.DBF`, `.CDX`, `.FPT`)
- **Character Encoding:** CP1252 (Windows-1252 Western European) / CP850 (DOS Portuguese)
- **Date Format:** `YYYY-MM-DD` / `DD/MM/YYYY`
- **Decimal Separator:** `.` (Period)
- **Currency:** MZN (Metical Moçambicano)
- **Deleted Record Flag:** Standard 0x2A asterisk deletion marker in `.DBF` headers
- **Indexes:** Compound index files (`.CDX`)
